## Description

FreeCAD MCP is a Model Context Protocol server that bridges FreeCAD (open-source 3D CAD software) with Claude AI. It enables natural language control of 3D modeling through Claude Desktop — users can describe parts and designs conversationally, and Claude generates the 3D geometry.

Key capabilities:
- Create and edit 3D objects via natural language
- Execute Python code within FreeCAD
- Capture screenshots of designs
- Access FreeCAD's parts library
- Manage documents and objects

The project is MIT-licensed Python code, supporting both local and remote network operation with security controls.
