## Novel Discoveries (4)

### 1. MCP Tool Result Size Override (`maxResultSizeChars`)
**Type**: technique | **Version**: v2.1.91
**File**: `pipeline/evaluation/pending/mcp-result-size-override-2026-04-03.json`

MCP servers can annotate individual tool results with `_meta["anthropic/maxResultSizeChars"]` (max 500,000 chars) to raise the per-result payload limit. Without annotation, large MCP results (DB schemas, Exa deep research, event-bus queries) are silently truncated. Server-side opt-in per tool result — no client config needed. Directly affects agent-event-bus and Exa deep_researcher payloads.

**Redundancy check**: NOVEL. MCP Tool Description Cap (v2.1.84) controls *description* truncation; this controls *result payload* truncation — orthogonal controls.

### 2. `disableSkillShellExecution` Settings Key
**Type**: technique | **Version**: v2.1.91
**File**: `pipeline/evaluation/pending/disable-skill-shell-execution-2026-04-03.json`

New boolean settings key that disables inline shell execution within skills, slash commands, and plugin commands. Narrower than `CLAUDE_CODE_SIMPLE` (restricts all native tools) — targets only SKILL.md shell blocks. Primary use: CI/CD sandboxing, untrusted marketplace plugin containment, read-only agent contexts.

**Redundancy check**: NOVEL. Distinct from `CLAUDE_CODE_SIMPLE` (all tools), `disabledMcpjsonServers` (MCP only), and Agent Spawn Restrictions (subagent hierarchy). Complementary controls.

### 3. Plugin `bin/` Executables
**Type**: technique | **Version**: v2.1.91
**File**: `pipeline/evaluation/pending/plugin-bin-executables-2026-04-03.json`

Plugins can ship executables under `bin/` that become invocable as bare commands from the Bash tool when the plugin is active. No global installation required. Enables self-contained plugins bundling CLI helpers alongside agents and skills. Evolution pipeline use case: heartbeat scripts, version-tracker, webhook-post could be packaged cleanly as plugin bin/ entries.

**Redundancy check**: NOVEL. Extends v2.1.85 inline plugin declarations — not duplicated by any existing capability.
