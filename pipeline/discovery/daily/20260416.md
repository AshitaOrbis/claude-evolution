### 4. HCOM — Hook-Based Inter-Agent Communication
**File**: `pipeline/evaluation/pending/20260416-hcom-inter-agent-hook-comms.json`
**Type**: skill / agent coordination pattern
**Source**: github.com/aannoo/hcom (206 stars, MIT, v0.7.1)

Real-time peer-to-peer communication between concurrent Claude Code agent instances via hooks + SQLite. Messages arrive mid-turn (between tool calls). @-mention targeting, transcript handoffs, PTY screen sharing across agents. Zero-dependency Python. Fills a gap: current multi-agent setup has no mechanism for sibling agents to communicate directly without routing through an orchestrator. Enables flat agent collaboration patterns.
