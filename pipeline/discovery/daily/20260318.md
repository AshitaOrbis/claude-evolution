## Novel Discoveries (3)

### 1. Claude Code v2.1.78 — StopFailure Hook, Plugin Persistent State, Plugin Agent Frontmatter

**File**: `pipeline/evaluation/pending/claude-code-v2178-2026-03-18.json`
**Type**: technique (Claude Code version features)

Key additions beyond v2.1.77 (last registry update):
- **`StopFailure` hook event**: Fires when a turn ends due to an API error (rate limit, auth failure). Enables automated error recovery without polling — different from existing hooks which fire on tool use or turn completion.
- **`${CLAUDE_PLUGIN_DATA}` variable**: Plugin-scoped persistent state that survives plugin updates. Enables stateful plugins without external storage.
- **`effort`/`maxTurns`/`disallowedTools` frontmatter for plugin-shipped agents**: Plugin authors can now constrain agent behavior at definition time (matching the agent spawn restrictions pattern already in registry, but extending to plugin-distributed agents).
- **Memory file timestamps**: last-modified timestamps added to memory files so Claude can reason about freshness vs staleness of memories (high relevance given this project's auto-memory system).
- **`modelOverrides` setting**: Maps model picker entries to custom provider model IDs (e.g., AWS Bedrock inference profile ARNs) — relevant for Bedrock deployments.
- **Streaming improvement**: Response text streams line-by-line; tmux passthrough notification support.

**Why it matters**: `StopFailure` hook and `CLAUDE_PLUGIN_DATA` are the most actionable. StopFailure fills a gap in error recovery automation (heartbeat and iterative-improve loops could use this). Plugin persistent state is relevant if/when plugin architecture is adopted over manual skill files.

### 2. Claude Dispatch — Mobile Remote Control for Desktop Cowork Sessions

**File**: `pipeline/evaluation/pending/claude-dispatch-cowork-2026-03-18.json`
**Type**: technique (Anthropic research preview)

Launched March 17, 2026. Allows a persistent Claude Cowork session running on a desktop to be triggered and monitored from a mobile phone. The async delegation pattern (start long task from phone → desktop executes → check back for results) mirrors the existing Tailscale SSH + tmux workspace pattern but as a native Anthropic UI feature. Currently Max plan only, Mac-based, research preview status.

**Why it matters**: The pattern itself (async persistent agent sessions with mobile handoff) is architecturally interesting. Not immediately integrable into the Claude Code CLI workflow but worth monitoring for API exposure. Low expected score (UI-only, no programmatic API, research preview).

### 3. Azure DevOps Remote MCP Server — Microsoft Official Public Preview

**File**: `pipeline/evaluation/pending/azure-devops-remote-mcp-2026-03-18.json`
**Type**: mcp_server
