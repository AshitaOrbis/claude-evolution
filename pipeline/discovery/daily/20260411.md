### 1. Agents as MCP Servers — Architectural Inversion Pattern
**File:** `agents-as-mcp-servers-pattern.json`
**Source:** HN item 44053754
**Priority: MEDIUM-HIGH**

New pattern where AI agents themselves act as MCP servers, not just clients. Any MCP-compatible tool (Claude Code, Cursor, etc.) can invoke agents by connecting to them via standard MCP protocol. ### 2. MCP Discovery API — Dynamic MCP Server Selection via Semantic Search
**File:** `mcp-discovery-api.json`
**Source:** HN item 46661173
**Priority: MEDIUM**

Agents can discover and select MCP servers at runtime via semantic search, rather than requiring all servers pre-configured in `.mcp.json`. An agent states intent ("I need calendar access") and receives matching server connection instructions dynamically.

Key distinction from Tool Search Tool: Tool Search Tool selects among already-loaded tools; MCP Discovery selects which servers to connect to before loading. Complementary, not redundant.

**Estimated score:** ~64 — NEEDS_RESEARCH (verify whether this is a spec, prototype, or shipping service).
