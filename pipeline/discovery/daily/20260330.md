## Novel Discoveries (4)

### 1. ANTHROPIC_DEFAULT_*_MODEL_SUPPORTS Env Vars (v2.1.84)

**File**: `pipeline/evaluation/pending/anthropic-default-model-supports-env-vars-2026-03-30.json`
**Type**: technique
**Status**: APPROVED (~77/100)
**Source**: https://github.com/anthropics/claude-code/releases/tag/v2.1.84

Three new env vars for Bedrock/Vertex/Foundry users: `ANTHROPIC_DEFAULT_OPUS_MODEL_SUPPORTS`, `ANTHROPIC_DEFAULT_SONNET_MODEL_SUPPORTS`, `ANTHROPIC_DEFAULT_HAIKU_MODEL_SUPPORTS`. These declare whether a pinned third-party model supports extended thinking and effort controls — fixing silent regressions where Claude Code assumed wrong capability presence for custom inference profiles. Companion `_MODEL_NAME`/`_MODEL_DESCRIPTION` vars customize the `/model` picker labels.

Distinct from existing `ANTHROPIC_DEFAULT_{OPUS,SONNET,HAIKU}_MODEL` (which set model IDs) and `ANTHROPIC_CUSTOM_MODEL_OPTION`/`modelOverrides` (which add picker entries). This fills a specific gap: capability declaration for already-pinned models.

**Recommended action**: Low-effort registry update alongside existing multi-model env var section.

### 2. `cog` Plain-Text Tiered Memory Cognitive Architecture

**File**: `pipeline/evaluation/pending/cog-plain-text-cognitive-architecture-2026-03-30.json`
**Type**: technique
**Status**: NEEDS_RESEARCH (~64/100)
**Source**: https://github.com/marciopuga/cog
**HN**: https://news.ycombinator.com/item?id=47524704 (114 points)

Conventions-only cognitive architecture for Claude Code implementing tiered memory (hot/warm/cold/glacier), thread synthesis (recurring topics promoted to synthesized files), and structured workflows: `/reflect` (reviews activity, extracts patterns), `/foresee` (forward planning), `/housekeep` (condenses and archives). Self-evolution enabled — the framework can update its own conventions.

Novel relative to our flat MEMORY.md system: tiered layers, automatic condensation policies, thread synthesis, glacier archival are all absent from our current approach. The integration question is whether specific patterns (especially tiering and condensation) can be cherry-picked without wholesale replacement.

**Caution**: Individual author, moderate HN signal (114 pts), unclear maintenance trajectory.
