### 1. v2.1.115 Four Production-Critical Bug Fixes

**File**: `pipeline/evaluation/pending/v2.1.115-bug-fix-cluster-2026-04-21.json`
**Type**: technique (version registry update)
**Source**: https://code.claude.com/docs/en/changelog

Four regressions fixed in v2.1.115 (~April 19):
- `--resume` regression: sessions pre-v2.1.85 failing with tool_use/tool_result mismatch error
- **Outside-root edit regression** (HIGH RELEVANCE): Write/Edit/Read failing on `~/.claude/CLAUDE.md` and other files outside project root when conditional skills/rules are configured — directly affects this workspace
- Config write storm: unnecessary disk writes on every skill invocation causing performance degradation
- `--bare` regression: MCP tools dropped in interactive sessions, enqueued messages silently discarded

The outside-root edit fix is the most operationally significant — every session that edits global CLAUDE.md files was affected if on versions between the regression introduction and v2.1.115.

### 3. CodeBurn — Task-Level Token Cost Analytics TUI

**File**: `pipeline/evaluation/pending/codeburn-token-analytics-tui-2026-04-21.json`
**Type**: technique
**Source**: https://github.com/getagentseal/codeburn (Show HN)

Interactive TUI that reads `~/.claude/projects/` JSONL transcripts and classifies interactions into 13 deterministic categories by tool usage patterns — no extra LLM calls. Provides cost breakdown by task type, tool, model, MCP server, project, and one-shot success rate per category.

Fills an observability gap: `ccusage` provides date-level cost; CodeBurn adds task-type granularity. No registry equivalent. Featured on Hacker News with positive reception. Estimated score: ~68-74/100.
