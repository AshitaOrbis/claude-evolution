## Novel Discoveries

### High Priority

**1. PreToolUse 'defer' Permission Decision (v2.1.89)**
Type: technique | File: `pretooluse-defer-headless-checkpoint-2026-04-02.json`

Headless pipelines can now pause mid-execution at a specific tool call by returning `'defer'` from a PreToolUse hook, then resume later with `claude -p --resume`. Enables true human-in-the-loop checkpoints in autonomous workflows without abandoning session context. High operational relevance for heartbeat/automation pipelines.

**2. claude.ai MCP Connectors Accessible from CLI (v2.1.89)**
Type: technique | File: `claudeai-mcp-connectors-cli-2026-04-02.json`

OAuth-authenticated MCP servers from the claude.ai web interface are now accessible from CLI sessions. Enables Google Workspace, Atlassian, Salesforce MCPs authenticated once via browser to work in terminal. Deduplication: local config wins on conflict.

**3. MCP list_changed Notification Support (v2.1.89)**
Type: technique | File: `mcp-list-changed-dynamic-tools-2026-04-02.json`

MCP servers can now push `list_changed` notifications to dynamically register new tools mid-session without reconnect. Relevant for auth-gated MCP servers that conditionally expose tools after login.
