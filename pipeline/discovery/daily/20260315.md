### 1. Claude Code Auto Mode (Research Preview)

**File**: `pipeline/evaluation/pending/claude-code-auto-mode-2026-03-12.json`
**Type**: technique (Claude Code feature)
**Preliminary score**: ~82 (approve-track)

Anthropic launched a research preview of **Auto Mode** on March 12, 2026. Claude evaluates each operation's scope and classifies it as low-risk (auto-approve) or high-risk (interrupt developer). Enabled via `Shift+Tab` cycling or `defaultMode: "auto"` in settings.json.

**Why novel**: Not in registry, not in pipeline. No redundancy triggers match ("auto mode", "defaultMode auto", "permission automation"). Distinct from: `CLAUDE_CODE_SIMPLE` (restricts tools), agent spawn restrictions (limits subagent hierarchy), PreToolUse hooks (static allowlists). This is Anthropic-native dynamic permission automation.

**Relevance**: High for iterative-improve loops and heartbeat runs — removes manual approval interruptions from long autonomous tasks. Includes prompt injection safeguards and admin-level restriction controls.

**Sources**: awesomeagents.ai, startuphub.ai, vktr.com, Reddit r/ClaudeCode, GitHub Issue #33587, Qiita

### 2. Autonomous Agent-Triggered Memory Compression

**File**: `pipeline/evaluation/pending/autonomous-agent-memory-compression-2026-03-15.json`
**Type**: technique
**Preliminary score**: ~58 (NEEDS_RESEARCH)

LangChain Deep Agents SDK (March 2026) introduced agent-autonomous memory compression: agents decide WHEN to compress based on content-value analysis rather than fixed human-set thresholds (e.g., "exit at 80%"). Uses tiered storage model (active context = RAM, archived summaries = disk). Related: Letta memory framework uses same OS-memory hierarchy metaphor.

**Why novel**: We have manual `/compact` + compact-with-instructions (IMPLEMENTED), but NOT agent-autonomous compression triggers. The novel element is content-value scoring driving the compression decision, not fixed context percentage.

**Why NEEDS_RESEARCH**: LangChain-specific mechanism; needs translation to Claude Code `/compact` + hooks pattern. PostCompact hook (v2.1.76) may be the integration point. Algorithm for content-value scoring unclear.

**Sources**: cryptopond.com (LangChain announcement), machinelearningmastery.com (Letta memory framework survey)
