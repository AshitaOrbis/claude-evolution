## Novel Discoveries

### 1. Seeing Like an Agent — Anthropic Tool Design Philosophy

**File**: `pipeline/evaluation/pending/seeing-like-an-agent-tool-design-2026-04-20.json`
**Type**: technique
**Source**: https://claude.com/blog/seeing-like-an-agent (Thariq Shihipar, published 2026-04-10)

Official Anthropic engineering post documenting internal methodology for designing AI agent tools. Three core principles:

1. **Progressive disclosure** — tools should surface just enough information for the agent to act without flooding context
2. **Seeing like an agent** — design tools by reasoning through the agent's perceptual model, not a human's
3. **Discoverability** — even well-designed tools fail if Claude can't discover or invoke them correctly

Concrete case studies in the post: AskUserQuestion (blocking modal preventing conversation-buried clarifications), Task tool (context-isolated delegation).

**Why it matters**: The progressive disclosure principle is directly actionable for how SKILL.md files and MCP tool descriptions are written. Complements the existing 2KB MCP tool description cap in the registry. Estimated score: ~74 (technique, first-party source, clear application to existing stack).
