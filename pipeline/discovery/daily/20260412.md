### 1. KAIROS — Unreleased Always-On Background Agent Daemon
**File:** `kairos-background-agent-daemon.json`
**Source:** Ars Technica / Codepointer Substack (Claude Code source leak analysis)
**Estimated score:** ~70 | **Confidence: MEDIUM** (source-leak, not official)

Found 150+ times in the v2.1.88 source leak. KAIROS is a persistent background daemon that runs even when the terminal is closed. Key mechanisms: periodic `<tick>` prompts for autonomous proactivity, PROACTIVE flag for surfacing unsolicited insights, 15-second blocking budget (long shell commands auto-backgrounded), append-only daily logs instead of MEMORY.md rewrites, and access to tools unavailable in normal sessions. Internal comments indicate a May 2026 launch target with a prior April 1-7 teaser.

**Distinction from existing patterns:** The heartbeat cron is user-scheduled intervals; KAIROS is a persistent daemon with autonomous tick-based agency that doesn't require user invocation. Architecturally different from Agent Teams (collaborative), this is a single always-running sentinel.

**Status:** Feature-gated (`feature('KAIROS')`), not user-activatable. **Monitor for May 2026 announcement.**

### 4. OTEL Tracing Opt-In Env Vars (v2.1.101)
**File:** `otel-tracing-opt-in-env-vars-v2101.json`
**Source:** GitHub anthropics/claude-code v2.1.101 release notes + Claude Code monitoring docs
**Estimated score:** ~65 | **Confidence: HIGH**

Three new env vars for Claude Code's beta OTEL tracing: `OTEL_LOG_USER_PROMPTS=1`, `OTEL_LOG_TOOL_CONTENT=1`, `OTEL_LOG_TOOL_DETAILS=1`. By default, prompt text and tool content are redacted from trace spans. These opt-in flags include them for debugging. Also: v2.1.101 injects W3C `TRACEPARENT` into Bash subprocesses when tracing is active — child-process spans correctly parent to the Claude Code trace tree. Community repo `ColeMurray/claude-code-otel` provides quickstart guidance.

**Relevance:** Heartbeat and pipeline cost monitoring. Integration possibility with the existing agent-event-bus observability pipeline.
