**Priority**: MEDIUM

### 2. MCP Response Injection — Runtime Security Gap ⭐

**Type**: technique (security)
**Priority**: HIGH
**File**: `pipeline/evaluation/pending/mcp-response-injection-defensive-pattern-2026-03-22.json`
**Hallucination risk**: LOW-MEDIUM (attack class is valid; specific CVE-2026-24052 unverified)

Security research demonstrates that MCP server **responses** (not server code) can contain adversarial instructions — a runtime prompt injection attack vector. Current security stack covers static code (mcp-guard, semgrep) and commits (security-auditor), but has **no coverage for adversarial content in MCP response payloads at runtime**.

**Why novel**: A gap in current security posture, not a tool to install. The fix is defensive pattern documentation and possibly adding response content validation to the OpenClaw output-validator.

**Registry status**: NOVEL — existing MCP security tools cover code, not runtime response content.
**Recommended action**: HIGH PRIORITY evaluate. Document defensive technique; update mcp-guard registry scope notes; consider output-validator extension.
**Score estimate**: 75-82/100 (APPROVED — document as defensive technique)
