## Discoveries Found

### 1. Xcode 26.3 MCP Integration (Apple) — NOVEL/FUTURE
**File**: `pipeline/evaluation/pending/xcode-26-3-mcp-server.md` (creating)
**Source**: apple.com/newsroom, 9to5Mac, Ars Technica (Feb 26, 2026)

Apple released Xcode 26.3 with native MCP server support. Xcode now exposes IDE capabilities
to external agents via `xcrun mcpbridge`. Claude Code can connect:
```
claude mcp add --transport stdio xcode -- xcrun mcpbridge
```

Key capabilities exposed to agents:
- Build and run iOS/macOS projects
- Run tests in simulator
- Project navigation and code inspection
- Side panel for agent task assignment with progress tracking

**Assessment**: NOVEL capability (first Apple IDE with native MCP support). However, it's
macOS-only — our environment is WSL/Linux. FUTURE status, same treatment as Grafana/Terraform.

**Adoption trigger**: If doing iOS/macOS development on macOS machine.

### 2. Firecrawl MCP Server — EVALUATION NEEDED
**File**: `pipeline/evaluation/pending/firecrawl-mcp-server.md` (creating)
**Source**: firecrawl.dev, 85k GitHub stars (mendableai/firecrawl)

Firecrawl is a web-to-LLM data extraction service with MCP server integration. Key features:
- `firecrawl_scrape`: Single URL → clean markdown (strips ads/nav/markup)
- `firecrawl_crawl`: Multi-page crawl (sitemap walking)
- `firecrawl_map`: Discover all indexed URLs on a site
- `firecrawl_extract`: Structured data extraction with JSON schema
- `firecrawl_search`: Web search with language/country filters
- Batch processing support
- Automatic retries with rate limiting

85k GitHub stars = top-tier community validation. The multi-page crawl and structured JSON
extraction are potentially novel vs our existing Exa `crawling_exa` (single URL) and WebFetch.

**Assessment**: Needs evaluation. Question is whether it adds enough vs Exa crawling + WebFetch
to justify API key dependency and cost model.

### 3. Claude Code Security CVEs (Informational)
**Type**: Security disclosure (already patched)
**Sources**: Check Point Research, The Hacker News, The Register (Feb 20-26, 2026)

Check Point Research disclosed two vulnerabilities in Claude Code:
- **CVE-2025-59536** (CVSS 8.7): RCE via malicious hooks in `.claude/settings.json`
  - Fixed in v1.0.87 (September 2025)
- **CVE-2026-21852** (CVSS 5.3): API key exfiltration via project-load flow
  - Fixed in v1.0.111 (October 2025)

**Impact**: Both already patched. No immediate action required.
**Lesson**: Never clone and open untrusted repositories without inspecting `.claude/` directory first.
**Action**: Add security note to registry about project file trust model.
**No discovery file needed** — informational update to registry security note.
