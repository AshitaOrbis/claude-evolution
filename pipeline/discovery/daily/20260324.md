## Novel Discoveries

### 1. Background Agent Partial Result Preservation
**File**: `pipeline/evaluation/pending/background-agent-partial-results-2026-03-24.json`
**Type**: technique
**Source**: releasebot.io (Claude Code v2.1.81+, March 2026)
**Estimated score**: 72

When a background agent is killed or interrupted, its partial results are now preserved in conversation context rather than discarded. Enables checkpoint-recovery patterns for long-running agents (heartbeat, integration). Distinct from Autonomous Subagent Resume (which handles cleanly-stopped agents) — this handles kill/interrupt scenarios.

### 2. Automatic Stale Tool Output Cleanup
**File**: `pipeline/evaluation/pending/stale-tool-output-auto-cleanup-2026-03-24.json`
**Type**: technique
**Source**: dev.to / releasebot.io (Claude Code 2026 feature)
**Estimated score**: 68

Claude Code automatically trims verbose tool call outputs from conversation history as they become stale, reducing token accumulation in long sessions. Different from `/compact` (manual, full-message summarization) — this is automatic and granular (targets tool results specifically). Needs verification of trigger conditions and configurability before integration.
